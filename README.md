# Password Strength Checker

A lightweight and responsive interactive web application built with HTML, CSS, and JavaScript that checks password strength in real time.

## Features

- **Real-time feedback**: Evaluates password strength as you type.
- **Dynamic progress indicator**: Visual color-coded strength bar (Weak, Medium, Strong, Very Strong).
- **Rule evaluation**:
  - Minimum 8 characters
  - Uppercase letters
  - Lowercase letters
  - Numeric digits
  - Special characters

## Project Structure

```
Password Strength Checker/
├── index.html   # Main HTML layout
├── style.css    # Modern UI styling
└── script.js    # Password evaluation logic
```

## How to Run

Open `index.html` in any web browser.
